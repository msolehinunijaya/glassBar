# Mac-style dock behaviour Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Magnification, launch bounce, Genie/Scale/Suck minimize effects with live minimized-window spots, and a dock on every screen, each with its setting.

**Architecture:** Magnified icons are drawn in a small transparent click-through webview window (`magnify`) above the launcher, because the dock's native glass covers its whole window; the dock itself only spreads the icon slots. Minimize effects are DWM thumbnails animated by Rust in a transparent `WS_EX_NOREDIRECTIONBITMAP` overlay window, using pure geometry from `src-tauri/src/effects.rs`. Extra docks are more `bar-*` webview windows; the window labelled `bar` stays the main dock that gets sounds and alerts.

**Tech Stack:** Tauri 2.12 (Rust, `windows` crate, DWM), Svelte 5 runes, vitest, cargo test.

**Spec:** `docs/superpowers/specs/2026-10-28-mac-dock-design.md`

## Review Focus

1. **Rapid minimize/restore of the same window** (double-click title bar spam): never two effects on one window, never a stuck thumbnail. Test in Task 5: starting an effect for a window that already has one cancels the first.
2. **Window closed mid-effect**: overlay must clear. Test in Task 5: `EffectRun` ends when the source is gone (`DwmQueryThumbnailSourceSize` fails) and unregisters.
3. **Pointer leaves the dock quickly or the dock auto-hides while magnified**: magnifier window hidden, bar length back to normal. Test in Task 2: `magnifyScales` with pointer `null` gives all 1.0; Task 3 hides on `pointerleave` and on `bar:away`.
4. **Monitor unplugged while All displays is on**: its dock closes and its reservation is released. Test in Task 7: `dock_monitors` drops monitors that are gone.
5. **App that never opens a window** (tray-only app, UAC prompt declined): bounce stops after 10 s. Test in Task 4: `settleBounces` at `now = started + 10_001` clears it.

### Task 4: Effect geometry (pure Rust)

**Files:**
- Create: `src-tauri/src/effects.rs` (pure, platform-independent, unit tested)
- Modify: `src-tauri/src/main.rs` (mod)

**Interfaces:**
- Produces: `#[derive(Deserialize, Clone, Copy, PartialEq, Debug)] #[serde(rename_all="lowercase")] pub enum Effect { Genie, Scale, Suck, None }`; `pub fn duration_ms(e: Effect) -> u32` (Genie 450, Suck 300, Scale 250, None 0); `pub fn frame(e: Effect, from: Rect, to: Rect, edge: Edge, t: f64, strips: usize) -> Vec<(Rect, Rect)>` returning `(source slice in source-window pixels (0,0,from.w,from.h space), destination rect in screen px)`; Scale returns one pair; Genie/Suck return `strips` pairs slicing across the axis perpendicular to the dock (horizontal strips for top/bottom, vertical for left/right). `t` is eased inside `frame` (ease-in-out for Genie, ease-in for Scale/Suck).

Genie algorithm (the one non-obvious body): for strip i with normalised position `p` (0 = side nearest the dock, 1 = farthest), phase 1 (`t < 0.5`) bends the sides: each strip's width lerps from `from` width toward `to` width by `bend(p, t) = (2t)·(1 − p)^2`, its along-dock centre lerps toward `to` centre by the same amount; phase 2 (`t ≥ 0.5`) slides all strips toward the dock, compressing their heights so the whole column's far edge moves from its phase-1 position to `to`'s far edge at `t = 1`. Suck = Genie with the centre target at `to`'s corner nearest the window and `bend` using `(1 − p)` (linear, harder).

  - Genie at `t = 1`: every dest inside `to` (allow 1 px rounding).
  - Genie at `t = 0.25` on a Bottom dock: the strip nearest the dock is narrower than the farthest strip.
  - Left dock Genie: strips are vertical (each source slice has full height).

Ticks every ~8 ms with `DwmFlush()` pacing. A new effect for the same `src` cancels the running one; a failed `DwmUpdateThumbnailProperties` / source gone ends the run; every end unregisters all thumbnails, hides the overlay, then calls `then`.
- Produces (platform trait): `fn suppress_native_animation(&self, hwnd: isize, on: bool) -> bool` via `DWMWA_TRANSITIONS_FORCEDISABLED`.
- Produces (commands): `effects_targets(window: WebviewWindow, t: EffectTargets)` with `EffectTargets { effect: Effect, per_window: HashMap<isize, RectCss>, end: Option<RectCss>, dock: RectCss }` (CSS px of that bar; Rust converts and stores per bar label); `app_restore_animated(id: isize)` plays the reverse effect from the window's target to its restore rect, then calls the existing activate/restore.
- Pill sends `effectsTargets` whenever icon layout or groups change (ResizeObserver on the row + `$effect` on groups), with `effect` already lowered to `'scale'` in Low mode and `'none'` when off; `per_window` maps each window id to its icon rect, or (when `minimizeToIcon` is off) to its spot rect if it has one; `end` = where the next minimized spot will appear (just past the last spot / divider).
- Target choice in Rust on minimize: `per_window[hwnd]` → else (`minimizeToIcon` off) `end` → else `dock` centre; the bar on the window's monitor if one exists, else the main `bar` (flies across monitors). Only the first App Launcher instance in the profile sends targets (Pill checks it is the first enabled `apps` widget in `config.profile().widgets`).
